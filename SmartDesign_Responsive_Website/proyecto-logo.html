Identidad Visual

Diseño de Logo

Propuesta visual moderna para representar una marca digital de forma clara y reconocible.

Descripción del proyecto

Se trabajó con formas geométricas, tonos azules y azul marino para comunicar tecnología, confianza y creatividad. El diseño fue pensado para funcionar tanto en una página web como en redes sociales.

Resultado

Una identidad visual limpia, escalable y fácil de reconocer en tamaños pequeños.
