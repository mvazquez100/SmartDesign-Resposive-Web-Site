Branding para Emprendimiento

Sistema visual sencillo para mantener consistencia entre sitio web y contenido digital.

Descripción del proyecto

El proyecto integra colores, tipografías y estilos de interfaz que ayudan a que una marca conserve la misma personalidad visual en diferentes plataformas.

Componentes del sistema

  • Paleta de azul, azul marino, blanco y grises suaves.
  • Jerarquía tipográfica para títulos, subtítulos y texto de lectura.
  • Tarjetas, botones y espaciado coherente para una experiencia uniforme.

Aplicaciones

Sitio web · Redes sociales · Presentaciones · Material promocional
