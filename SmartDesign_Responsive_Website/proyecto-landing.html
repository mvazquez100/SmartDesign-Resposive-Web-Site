Landing Page Empresarial

Concepto de página responsiva orientada a convertir visitantes en clientes potenciales.

Descripción del proyecto

El objetivo fue diseñar una interfaz clara con una propuesta de valor visible, botones de llamada a la acción y secciones que se reorganizan automáticamente según el tamaño de la pantalla.

Elementos principales

  • HTML semántico para mejorar organización y accesibilidad.
  • Grid de Bootstrap para adaptación a móvil, tableta y escritorio.
  • Botones de acción y jerarquía visual consistente.

Tecnologías

HTML5 · CSS3 · Bootstrap 5
