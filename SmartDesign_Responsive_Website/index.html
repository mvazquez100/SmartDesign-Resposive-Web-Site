Acerca de mí

Diseño web con propósito

Soy Miguel, diseñador y desarrollador web de Smart Design. Me especializo en crear experiencias digitales limpias, rápidas y fáciles de usar para emprendedores y pequeñas empresas.

Mi enfoque combina estructura HTML semántica, diseño responsivo y una identidad visual consistente. Cada proyecto se desarrolla pensando en la claridad del mensaje, la navegación y la adaptación a teléfonos, tabletas y computadoras.
